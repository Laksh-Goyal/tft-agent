# Coding Rules

These rules guide all code written in this project. Follow them consistently.

1. **Keep it Simple (KISS):** Write simple solutions. Avoid complex tricks that confuse others.
2. **Don't Repeat Yourself (DRY):** Reuse code. Do not copy and paste the same logic.
3. **Use Meaningful Names:** Name variables and functions clearly. Names must tell you what they do.
4. **Keep Functions Small:** Make each function do only one job. Short code is easy to fix.
5. **Avoid Magic Numbers:** Replace raw numbers with named constants. Give every value a clear label.
6. **Favor Early Returns:** Handle errors or exit conditions right away. This stops deep nesting in loops and if statements.
7. **Comment the "Why":** Let the code show how it works. Use comments only to explain why a choice was made.
8. **Follow Style Guides:** Use standard formatting rules for your language. Consistent code is easier to read.
9. **Test Your Code:** Write automated tests. Check that your work functions correctly before shipping.
10. **Leave Code Better:** Clean up messes when you see them. Improve the codebase step by step.
